## 1. 为什么（四条证据链 + 一条文献共识）

阶段二按冻结判据（E1 ≥ 80% 且 E2 ≥ 90%）未过线，错误结构给出四条相互印证的证据：

1. **深度输物理**：`phys_envelope`（零训练包络谱谐波比）73.42% > 全部深度臂留出数字；
2. **Normal 塌**：零标注四臂 Normal 召回 0/288，根因是 logspec 停在载波域（台架特异），
   且判别式 softmax 把"健康"学成了"源域谱形另一侧"；
3. **未见轴承塌方**：池同轴承新工况 71.2% vs 未见轴承 35.4%——监督收益大半是记忆；
   DSBNet 临界样本量规律（~25/类临界、~50/类稳定）与 K38(≈13/类)→K116(≈39/类) 的
   +40pp 跳变定量一致，且 **PU 上限 116 单元（均值 ~39/类）决定了纯监督永远到不了
   ~50/类稳定区**——泛化缺口必须由特征补，不是加预算能解决的；
4. **统计对齐负迁移**：`mmd_marginal` 低于 `joint` 12/12，DG 综述 §5.3 同款结论
   （源域间不变 ≠ 未见目标域不变）。

文献共识（12 篇详析）：**物理先验前置 + 一分类语义的 Normal + 数据增强替代统计对齐
+ 决策级融合**是对症路线；瓶颈在输入与表示，不在模型容量（`ce_K116` in-sample
96.9% 为证）——**MSRS-ABiLSTM 结构不动**。

另有一条今日核实的池构成证据：无标签 medoid 选标**系统性饿死 Normal**
（K19 池 N/OR/IR = 2/11/6，占 10.5% vs 基率 20.7%；K38 池 5/20/13）。

## 2. 决策

### D2 ✅ 代表监督臂改 `ce_K19`（2026-10-14 用户确认）

K38 池占 116 单元的 32.8%，"少样本"语义太弱；K19 占 16.4%。
`ce_K116` 保留作全监督天花板参照；**K38 不重训**，阶段二结果作历史参照。
注：K19 池 Normal 只有 2 个单元，饥饿最严重——配合 D6（GG 重选标）恰好构成
"选标效应"对照，这是选 `ce_K19` 的额外好处。

### D1 ✅ 双通道输入：logspec256 保留 + 物理通道（~25 维，先写死）

模型输入从 `(B,1,256)` 变 `(B,2,256)`（第二通道物理特征补零对齐到 256 维）
或 `(B,1,256+25)`——**具体拼接方式实现前定死一种**。物理通道构成（逐窗计算，
特征落回 512 窗格与 logspec 窗格对齐；包络谱分析窗为 2048 点，见第 1 项）：

1. **阶次对齐包络能量（~16 维）**：Hilbert 包络谱上，取该轴承 BPFO/BPFI/BSF/FTF
   及 2–4 倍频处的局部能量（±2 bin 邻带积分，即 IES 口径）。频率由
   `bearing_facts.py` 的逐轴承几何参数 × 工况转速解析得到——CWRU 与 PU 各算各的，
   **特征语义跨台架一致**（这是治证据链 2/3 的核心）；
   **分析窗（2026-10-14 定，含当日修订）：物理通道的包络谱在 2048 点分析窗、
   1024 步长上计算（50% 重叠——沿 v7 冻结管道 512 窗/256 步长的等比缩放，
   唯一非任意的定法），特征落回 512 窗格用最近中心映射（相邻 4 个 512 窗格
   共享同一分析窗特征——包络统计在 170 ms 内准平稳，粒度损失到不了三级
   聚合的判据层）**——
   512/1024/2048 点窗的 Hann 主瓣全宽分别为 93.8/46.9/23.4 Hz，N09 的
   BPFO/BPFI 差 28 Hz 折合 1.2/2.4/4.8 bin：512 不可分、1024 在瑞利限边缘、
   2048 干净可分且每窗冲击数翻倍（N09 下 ~8 次/窗），转速周期内平稳性仍成立
   （170 ms ≈ 2.5 转频周期）；此为跑前由分辨率算术先验确定的冻结值，非结果回调；
   **logspec 通道仍按 512 窗计算**——理由是**归因隔离**而非可比性：深度臂输入
   不变，阶段三深度臂的任何变化才能归因于新增模块（D9 一次只动一个模块）；
   代价声明明确三级不可比，"与阶段二可比"不成立也不作为理由。logspec512
   （1024 点窗）可能更好——**未被排除**，若要检验须加独立对照臂（待确认 #10），
   不得与物理通道同时改动混入主线；
2. **时域统计（9 维）**：均值、方差、峰峰值、峭度、RMS、峰值因子、脉冲因子、
   波形因子、裕度因子（王楠同款）——补回 logspec 被抹掉的幅值/能量信息；
3. ~~**散射一阶带能量（8 维）**~~ **不进（2026-10-14 用户确认）**：语义与
   (1) 的邻带能量部分重叠、8 维全新冻结自由度；"共振带能量是否冗余"由 D7
   的 RS 约简假设检验回答——先用最小特征集（1+2 项，~25 维）跑通，散射带能量
   若被检验证明有依赖度再后补（作为消融而非主线）。物理通道定为 ~25 维。

**CWRU 侧同款计算（两侧对称，这是"物理锚"的全部含义；2026-10-14 补充）**：
- 这里的"双通道"指**特征通道**（logspec + 物理），不是 v6 的 DE/FE 传感器通道；
  CWRU 的 DE/FE 仍是独立单通道样本，每个样本按自己所属轴承算物理通道；
- 新增 CWRU 轴承事实表（模式同 `bearing_facts.py` 的 32 行 PU 表 + 自检）：
  DE = 6205-2RS JEM（官方倍数 BPFO 3.5848 / BPFI 5.4152 / BSF 2.3572 /
  FTF 0.3983 × fr）、FE = ZA-2115（6203 同族，BPFO/BPFI ≈ 3.05/4.95 × fr，
  与 PU 的 3.071/4.929 同族）；转速按文件名负载档解析（1797/1772/1750/1720 rpm，
  复用 v7 现有解析）；
- 逐窗流程两侧逐字相同（**2048 点分析窗、1024 步长（50% 重叠）** → Hilbert 包络 → 包络谱 →
   该轴承特征频率 ±2 bin 及 2–4 倍频能量，特征落回 512 窗格——与 PU 侧 D1 第 1 项
   完全同款）。**同一维特征在两侧语义一致**（第 1 维永远是
   "BPFO 一阶邻带能量"）——跨域对齐不靠统计（MMD 已证失败），靠这个解析锚。

**代价声明（必须写进冻结记录）**：
- 与阶段二全部数字**不可比**（输入变、选标变、臂变——三级差异，同 v6→v7）；
- 物理通道引入新自由度（频带/邻带宽/统计量清单），**本表即冻结值，看结果前不得调**；
- N09 物理墙**部分缓解但不消失**：2048 点分析窗下一阶 BPFO/BPFI 可分（间距
  28 Hz > 主瓣 23.4 Hz），但 2×BPFO = 92.1 Hz 与 BPFI = 73.9 Hz 差 18.2 Hz
  仍小于主瓣——倍频渗漏在 BPFI 邻带残留；N09 预期从"物理不可分"改善为
  "部分可分"，低分预期仍在，分组并报照旧（CWRU 1797 rpm 时 BPFO/BPFI 差
  54.8 Hz，任何窗长下都可分）；
- 特征缓存按 D9 纪律升版本号（`v8_phys25_12k_drop_ka08_v1` 之类）。

### D3 ✅ Normal 单类通道 + Ball 拒识（E1/E2/P_ball 口径不动）

- **Normal 单类**：在**物理特征**（D1 的 1+2 项）上训单类 SVM（ν 固定 0.05），
  源域 Normal 窗训练、源验证集标定阈值（99% 分位）；目标域得分作为 Normal 的
  独立证据通道。**明确禁止**在 logspec 上建单类——域间隙会原样继承（文献详析 §4）；
- **Ball 拒识**：Ball 通道输出改 max-min 偏差规则语义（最大后验低于阈值即不判 Ball），
  `adabn` 式 P_ball=31% 的传导激活从此没有出口；
- 判据不动：拒识只影响 P_ball 变小，不改分母与算法。

### D4 ✅ 4 源 DG 臂：`mixup4src` / `coral4src`（利用被浪费的多源结构）

`datasets/cwru.py` 的 `SOURCES = ("Normal","12k_DE","12k_FE","48k_DE")` 就是 4 个
源域，阶段二从未用作多源 DG。新增两个零标注臂：
- `mixup4src`：4 源间 Dirichlet 插值（样本层 + 特征层双 Mixup；Dirichlet α=1.0
  对称，训练前写死）——DG 综述 PU 最难任务上唯一 >40% 的方法；
- `coral4src`：4 源 CORAL 对齐（α=0.2，综述经验值写死）——综述四种对齐法中
  唯一一致优于纯训练者。
**代价声明**：4 源治的是 CWRU 内部采集设置差，CWRU→PU 的台架级间隙仍在——
预期是与 `joint` 的差距修正，不是判据达标手段。

### D5 ✅ 决策级融合臂：`fusion_joint` / `fusion_ce_K19`

单元级 4 路概率之后融合：`deep softmax 概率 × Normal 单类得分 × phys 规则分`
→ 固定权重（源验证集上网格搜索后冻结，只用源域，不碰目标标签）→ **输出仍是
4 路概率**，E1/E2/P_ball 与三级聚合完全不动。融合置信度低于阈值的单元列入
**拒判辅助报告**（不进 E1 分母）——同时充当 KB 事后分析想要的"不确定带"。

**与既有"融合"的区别（2026-10-14 补充，避免混淆）**：

| | v6 `file_fused` | v7 三级聚合（阶段二） | 本方案决策级融合 |
| --- | --- | --- | --- |
| 融合对象 | 同一模型，同一样本的 DE/FE 两个测点 | 同一模型，同一传感器的 20 次重复测量 | **三个异构预测器**：深度 softmax + Normal 单类 + 物理规则 |
| 信息性质 | 互补信息（两条传递路径） | 冗余信息（方差缩减，阶段二方案 D11 自己声明达不到独立样本理想值） | **互补错误结构**（已实证：深度缺 Normal、物理缺 IR，错位不重叠） |
| 融合时机 | 记录级聚合内部 | 窗口→记录→单元三级内部 | 单元级聚合**之后**，最终 4 路概率上 |
| 融合方法 | 等权平均（协议固定） | 等权平均（阶段二方案 D11 冻结；**注意与本文 D11 浅层贝叶斯不是同一决策**） | 固定权重（源验证标定后冻结）+ 拒判选项 |

一句话：以前的两种融合都发生在"一个模型的多次测量"内部（本身就是三级聚合），
这次融合的是"多个互补的预测器"——三级聚合原样保留，融合层是它下游的新一级
（吴凡消融证据：先验模块值 36pp，0.612→0.974）。

### D6 ✅ GG 重选标（`selection_gg.json`，不覆盖 v7 冻结产物）

`selection.py` 换 Gath-Geva 模糊聚类（自适应协方差，治 k-means 球形假设对低方差
Normal 紧簇的覆盖不足）+ XB 有效性指标定 k（搜索范围沿用 [6,20]）。落盘新文件，
与旧 `selection.json` 并存；**新旧池的类别覆盖诊断都并报**（标签只用于事后诊断）。
诚实声明：选标不许用标签，饥饿只能缓解并报告；若 GG 后 Normal 覆盖仍 < 基率，
这本身是可报结论（无标签主动学习的类覆盖偏差）。

### D7 ✅ `svm_phys` 浅层臂 + RS 约简假设检验

- `svm_phys`：物理特征（D1 的 1+2 项，~25 维）上 RBF-SVM（`probability=True`
  Platt 校准出概率，走同一三级聚合管道），源域训练 + K19 适配池微训，
  c/g 网格搜索写死范围——治"适配=记忆"（ERM→SRM）；
- **RS 约简作零训练假设检验**：在 K19 池上算各特征的依赖度/重要度，验证
  "特征频率包络能量是核属性、共振频带能量是冗余属性"——无论结果如何都写进报告。

### D8 ✅ `phys_envelope_v2` 锚升级（阶段三开跑前必做，零训练）

单峰比值 → **IES**（特征频率 ±2 bin 邻带积分，与 D1 物理通道同口径——
**含 2048 点分析窗**，锚与通道不同窗就不构成对照）+
**LEOC**（对数平方包络 + 阶次循环分量，抗转速，打 N09）+ **EEMD 去噪前端**
（IMF 相关系数 >0.5 保留）。OWES 若工程量大推迟（❓ **唯一遗留可选项**，见待确认 #11）。目标把锚推到 **80%+**，
防止"新方法赢了旧锚"的假象归因。

### D9 ✅ 消融纪律（一次一个模块，顺序写死）

物理通道（D1）→ Normal 单类（D3）→ 4 源对齐（D4）→ 融合层（D5）。
每步对照冻结基座：`joint` / `ce_K19` / `phys_v2`。**新臂只在与上一模块的差集上
归因**，不跨模块联合归因。

### D10 ✅ 判据与口径原样沿用

E1 ≥ 80% 且 E2 ≥ 90%（116 单元宏平均）、三级聚合（窗口→记录→单元等权）、
P_ball 并报、未见轴承分组并报、75% 文献锚（对 E2）、判据/池/臂/配对链训练前写死。
**新一轮数字与阶段二不可比，判据本身可比**（同尺子量新一轮）。

### D11 ❌ 浅层贝叶斯（DSBNet 式，P2）本轮不做（2026-10-14 用户确认）
BiLSTM 输入投影层 μ/σ 重参数化 + KL（β 单超参）。有临界样本量证据、无跨台架证据。

### D12 ❌ record 级 VMD 包络熵加权聚合臂（P2）本轮不做（2026-10-14 用户确认）
三级聚合第二级改无标签质量加权（softmax(−E_p/T)，T 写死）。**不改等权主口径**，
只作新臂并报；VMD 参数（k 网格 3..9）无标签准则选定。

### D13 ✅ 阶梯 2（art2real）本轮不做（2026-10-14 用户确认）
主线收敛为 CWRU→PU 单线。物理通道对真实损伤的优势（phys 的 real 组 66.7% >
深度 50.3%）作为设计依据保留在记录里，阶梯 2 延后另行安排。

### D14 ✅ 工作根：新目录 `rbop_diagnosis_v8`（2026-10-14 用户确认）
v7 目录与 outputs 只读；`_v7.py` 式隔离加载（模式同 `_v6.py`）。

## 5. 不做什么（有明确反证或冗余）

- GAN 生成增强（DG 综述：样本与原始高度相关）、DAEL（最大偏移任务上最差）、
  全层 BNN（难收敛）、MSESSA 类元启发式（网格等价）、MLDG（成本最高证据不强）；
- **不改** MSRS-ABiLSTM 结构、**不改**判据、**不重训** K38、**不加**新数据集；
- 不宣称阶段三数字与阶段二可比（三级差异声明）。
