## 1. 选型硬约束（由 v6 协议反推）

v6 模型头固定 4 类、输入固定单通道 512 点 @12 kHz。外部数据集要过的闸门：

| 约束 | 要求 | 违反后果 |
| --- | --- | --- |
| **类别空间** | 必须含 **Normal + IR + OR**；无 Ball 时按 D1 保留 4 类头做开集（PU 即此情形），或退化为 3 类闭集问题（旧版写"头部要砍成 3 类"已被 D1 推翻） | 头部维度不匹配或需开集口径 |
| **目标域文件数** | 少样本适配要按"标注池 vs 测试"切分，且有标签可得 → 池/测试两边都要够厚 | 文件数 ≲ 40 时测试指标的记录级分辨率粗于判据容差 |
| 采样率 | 原采样率与 12 kHz 的比是可约简的有理数（`resample_poly` 精确重采样） | `agents.md` 目前写死"48k 只允许 `resample_poly(x,1,4)`"，对外部数据必须重新声明 |
| **窗长物理尺度** | 512 点 @12 kHz = **42.67 ms**；低速台架单窗不足 1 个冲击周期 | 特征直接失效（判据：`BPFO × 42.67 ms ≫ 1`） |
| 通道独立性 | v6 把 DE / FE 当独立单通道样本 | 单传感器数据集评估格数减半，`file_fused` 融合口径**改形而不作废**（已由 D11 定：跨 20 文件 within 单元融合；旧版写"失效"已被推翻） |
| 文件数 | 选标协议要在候选集上跑 k-means（`k∈[6,20]`）+ silhouette | 文件数 ≲ 20 时阶段一那套选标不可移植 |
| 许可证 | 论文需要可引用的许可（CC BY 4.0 最优） | "未声明许可"的数据集不能进正式实验章节 |

## 3. 会破坏 v6 冻结协议的地方（必须先决策，不能顺手改）

1. **重采样规则**。**v6 的** `agents.md` 写死"48k 只允许 `resample_poly(x, 1, 4)`"（❗v7 的 `agents.md` 已扩成 gcd 通式，此处指 v6 旧规则）。外部数据集的采样率是 20 / 25.6 / 40 / 50 / 51.2 / 64 / 200 kHz，全部可写成精确有理数比：

   | 原采样率 | 到 12 kHz | 数据集举例 |
   | ---: | --- | --- |
   | 64 kHz | `resample_poly(x, 3, 16)` | Paderborn |
   | 51.2 kHz | `resample_poly(x, 15, 64)` | HIT-SM |
   | 50 kHz | `resample_poly(x, 6, 25)` | JNU |
   | 40 kHz | `resample_poly(x, 3, 10)` | UPM CITEF |
   | 25.6 kHz | `resample_poly(x, 15, 32)` | SDUST / HUSTbearing / DLR / XJTU-SY |
   | 20 kHz | `resample_poly(x, 3, 5)` | Saarland |
   | 200 kHz | `resample_poly(x, 3, 50)` | Ottawa 2018 |

   建议把规则显式扩写成"统一 `resample_poly(x, 12000/g, fs/g)`，`g = gcd(12000, fs)`"，并说明这不改变"每窗 42.67 ms"的物理口径。这是**扩写**不是**替换**，48k 那条仍然是它的特例。
2. **通道口径**。外部数据集多为单传感器（JNU、DLR、Saarland 等）。v6 的评估单元是"文件 × 通道"，单通道数据集的格数会减半，`file_fused` 融合口径**改形**：v7 已定为"跨 20 个文件 within 一个单元"的单元级融合（方案 D11），不是作废（❗旧版写"直接失效"已被 D11 推翻）。
3. **选标协议**。v6 的"最小够 95% silhouette 的 k + 每簇 medoid"依赖候选集规模与簇结构，换数据集后 `k` 与 `K` 必然变化。这正是被推迟的协议 Q2（标注预算 `p`）；阶段二的"迁移"若包含目标域标注，要先做 Q2。
4. **断言的物理前提**。单窗覆盖冲击周期数 ≈ `BPFO × 42.67 ms`。低速台架（UPM CITEF 200 rpm、JUST 2 rpm、DLR 60 rpm）单窗不足 1 个周期，任何结果都不能与 CWRU 对照解读。选目标域前先算这个数。

## 4. 建议的候选组合（供讨论，非结论）

以"源域 = CWRU 153 文件（四类）+ 目标域有标签"为前提。因为要做**外部测试 + 少样本适配**，目标域的第一优先级从"分布差距大"变成"**标签可靠 + 类别齐全 + 文件数够切池/测试**"，第二优先级才是跨域难度：

| 角色 | 数据集 | 文件数是否够 | 理由 |
| --- | --- | --- | --- |
| **主目标域（同型轴承跨台架）** | **SDUST（6205，四类含滚动体）** | 6 恒速 + 3 变转速 × 4 载荷 × 10 状态，**需核实**是否按文件切分 | 与 CWRU 驱动端同型轴承、不同台架；类别逐项对应；许可是唯一障碍 |
| **主目标域（三类，真实损伤）** | **Paderborn（6203）** | 32 轴承 × 4 工况 × 20 次测量，**充裕** | 唯一同时含 EDM 人工损伤与加速寿命真实损伤的数据集；6203 与 CWRU 风扇端同型；需接受 3 类口径 |
| **类别逐位对齐** | **JNU** | 4 类 × 3 转速，**需核实文件粒度** | 恰好 Normal/Ball/IR/OR，头部零改造；50 kHz |
| 多工况域泛化 | HUSTbearing | 9 状态 × 11 工况，**充裕** | 有官方 DG 基准协议可引用，适合做"多目标域"扩展 |

原先列的三条轴（同型跨台架 / 人工→真实 / 类别对齐）仍然成立，只是**排序变了**：现在"标签可靠 + 够切池/测试"优先，"跨域难度"退到第二。
