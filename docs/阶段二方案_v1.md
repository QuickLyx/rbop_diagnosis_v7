## 2. 决策

### D1 ✅ 保留 4 分类头，Ball 缺失就不管

源域仍训 4 类（`Normal / Ball / IR / OR`），分类头、损失、`model.py` 的 `n_classes=4` **全部不动**。PU 上 `Ball` 没有真样本，模型的 `Ball` 输出通道在目标域只会产生**假阳性**。

好处：阶段一关于"Ball 类信号弱、与相邻类混淆"的结论可继续沿用；源模型与阶段一同构，代码零改造。
代价：头号准确率数字内含一个"Ball 假阳性"惩罚，**不可与 CWRU 内部数字直接对照**。所以 D6 不是可选项。

### D6 ✅ 开集评估口径：E1 作主判据，E2 与 `P_ball` 并列分解

| 口径 | 做法 | 含义 | 风险 |
| --- | --- | --- | --- |
| **E1 四路 argmax（主判据）** | 直接在 4 个 logits 上取 argmax；判成 `Ball` 即算错 | 诚实、无后手；把"未知类拒绝能力"计入总分 | 数字偏低；**无法与 PU 原论文的 3 类口径直接比** |
| E2 三类掩码重判 | **先把 `Ball` logit 置零再对全部样本重新 argmax** | 把"域迁移能力"从"未知类识别"里剥出来，可与文献对标 | **用了目标域先验**（用了"PU 没有 Ball"这个知识），必须显式声明 |
| `P_ball` Ball 误判率 | 4 路 argmax 下被判成 `Ball` 的比例 | 开集难度的单数字度量 | —— |

固定输出三行，缺一不可（❗❗早期版本 E2 有两个不等价定义——表格行写"掩码后重判"、公式块写"判对/(全部−被判成 Ball 的)"即条件准确率；两者是不同统计量，且后者恒等于 E1/(1−P_ball)、不提供新信息。2026-10 用户确认：**E2 取掩码重判口径**，公式如下）：

```
E1       四路准确率     = 4 路 argmax 判对数 / 全部 N
E2       三类掩码准确率 = Ball logit 置零后 argmax 判对数 / 全部 N（分母与 E1 相同）
P_ball   Ball 误判率    = 4 路 argmax 判成 Ball 的数 / 全部 N
```

**层级与平均方式（与 D3 冻结一致）**：三个数都在**单元级（116）**上算，`E1/E2` 用**宏平均**（按 Normal/IR/OR 三类各算准确率再取均值；`P_ball` 为全样本比例）。记录级（2,319）作并报口径，同样算法。

**E2 的工程实现澄清**：上文“Ball logit 置零”指三类掩码排除该候选。实际必须在窗口 softmax、记录均值、单元均值后的**聚合概率**中把 Ball 项置零再 argmax；不能直接给原始负 logits 的 Ball 项赋 0，否则 Ball 仍可能最大，与“三类重判”相违。分母不变，不删除任何 Ball 误判样本。

`P_ball` 本身就是一个可报告的发现：**源域独有的类在目标域上会吃掉多少样本**。若 `P_ball` 很高（比如 OR 大量塌向 Ball——v6 在 `48k_DE` 上测过 OR→Ball 占 72% 的错误），就直接指向阶段三的开集识别课题，不需要重新设计实验。

⚠️ 两条口径在**看到任何 PU 结果之前**写死。

### D2 ✅ 留出单元 = **轴承×工况 = 116 条**（与 D5 同一决定）

- **划分与评估是同一个单元级**：池与测试都在 116 个单元上切，不得重叠；
- 标签仍是轴承的属性，同一单元内的 20 个记录共享标签；

- 代价声明与补充指标（未见轴承分组）见 D5。

**必须付的两条代价（写进冻结记录）**：
1. **声明这条协议衡量的是什么**：对新记录（可能同轴承、新工况）的泛化，**不是**对未见物理轴承的泛化。
2. **补充指标（❗旧版数字作废重算）**：池占多少轴承**逐臂落盘后才知道**——`ce_K{k}`（k≤20 个 medoid 单元）最坏可覆盖 20 个轴承（剩 9 个未见），最好可低至 ⌈k/4⌉ 个；`ce_K116` 全标时 0 个未见。把 116 个单元按"该单元的轴承是否进过池"分组，同一轮训练**零额外算力**就能同时报"含已见轴承"与"仅未见轴承"两个准确率——但**仅当未见组非空时才报**（旧版"池最多占 8 个轴承、至少 21 个未见"是已废弃的轴承级单元方案的残留算术）。

### D11 ✅ 三级聚合口径：窗口 → 记录 → 单元

❗初稿写"`file_fused` 融合口径作废"，同时又写轴承级平均"天然就是融合口径"——两句话自相矛盾而未察觉。融合**没有作废，是改形了**：从"跨通道 within 一个文件"变成"跨 20 个文件 within 一个单元"。

| 层级 | v6 (12k_FE 测试) | v7 (PU 主口径 29 轴承) | 聚合方式 |
| --- | ---: | ---: | --- |
| 窗口 | ~16,546 | **216,350** | 模型前向最小单位，softmax 在这层做（trainer.py:168） |
| **记录级** | 70（35 文件×2 通道） | **2,319**（每文件 1 通道；29×4×20−1 截断） | 同记录内全部窗口概率**等权平均**（trainer.py:176） |
| **单元级** | 35（跨 2 通道融合） | **116**（跨 20 文件融合） | 同单元内记录级概率**等权平均**（对应 evaluate.py:84） |

❗❗早期版本本表混用两个人口：窗口写 238,752（全 32 轴承）、记录级写 2,559（全 32 轴承）——但单元级 116 只覆盖主口径 29 轴承（= 2,319 条记录 / 216,350 窗）。KB 的 240 条记录在四类空间无真值（`bearing_facts` 映射为 `None`），**不能进 E1/E2 分母**。全 32 轴承口径（238,752 窗 / 2,559 记录）仅用于 KB 事后分析（D4，只报预测分布，不算准确率）。另：v6 侧的窗口数旧版写 ~8,220，实为**仅 DE 单通道**数（实测 8,273）；DE+FE 双通道实测 16,546。

**操作定义**（对齐 v6 代码）：
- 单元级概率 = 该单元全部记录级概率的等权平均（每条记录内部已对窗口平均过）；**每个单元 20 条记录，唯一例外：`KA08×N15_M01_F10` 为 19 条**（官方截断文件整条丢弃，数据事实 §2.6-1/6）；
- **不是**把 ~1,860 个窗口直接混在一起平均 —— 数值上几乎等价（窗数差 ≤3%），但保留"记录"层的可追溯性，且顺手报出记录级指标，零额外算力；
- argmax 在**单元级概率**上做 → 1 个单元 1 个结论；
- 同 v6 的纪律：聚合时若发现记录数与上述预期不符、或同单元内真值不一致，**直接报错不静默降级**（对应 evaluate.py:81-84）——19 条的例外是预期内，不触发报错。

**报告口径**：主判据 = **单元级（116）**；记录级（2,319，主口径）并报。这复刻 v6"记录级 + file_fused 并报"的纪律，且是**事先声明**，不是 v6 那种事后决策。

**信息性质必须写明**：v6 跨通道融合是两个**不同测点**（互补信息）；v7 跨 20 文件是**同一测点的重复测量**（冗余信息）。机制相同，增益来源不同——v7 是方差缩减，且这 20 次测量是连续采集、高度相关，缩减达不到独立样本的理想值。**不能宣称两者互相支持。**

**源侧不变**：CWRU 源域验证仍走 v6 的两步（记录级 → 跨 DE/FE 文件级），因为源域还是双通道。两套聚合规则在 `evaluate.py` 里并存，按数据集选择。

## 3. 特征与窗长口径

### 3.1 重采样规则扩写（写进冻结记录）

v6 是 `resample_poly(x, 1, 4)`（48k→12k）；PU 是 64 kHz。建议**扩写**为通式（48k 那条成为特例，不是被替换）：

```python
g = math.gcd(TARGET_FS, src_fs)          # TARGET_FS = 12000
y = resample_poly(x, TARGET_FS // g, src_fs // g)
# 64 kHz -> resample_poly(x, 3, 16)；48 kHz -> resample_poly(x, 1, 4)
```

**物理口径不变**：每窗仍是 512 点 @ 12 kHz = **42.67 ms**。这是跨数据集可比性的全部依据。

### 3.2 窗长物理可行性

单窗覆盖冲击周期数见 `数据事实_CWRU与Paderborn.md` §2.9。全量实测（32 个轴承、2560 个文件）得出**两个削弱方向**：

| 工况 | BPFO 周期/窗 | 外圈轴承 BPFO 比中位 | 判读 |
| --- | :-: | ---: | --- |
| `N15_M07_F10` | 3.28 | **11.45** | 基准（最强） |
| `N15_M01_F10` | 3.28 | 10.90 | 正常 |
| **`N15_M07_F04`** | 3.28 | **7.14** | **小径向力（400 N）削弱，实测新发现** |
| **`N09_M07_F10`** | **1.97** | **6.02** | **低转速（900 rpm）削弱，最不利** |

两者相差 1.9 倍。都仍 ≥1 个周期，不构成失效，但**逐工况报告时必须单独标注**，不能把它们的低分当作方法失败。如果将来要动窗长，这里是唯一的理由。

### 3.3 `logspec512` 沿用，**256 维不改**

512 点窗的 rFFT 只有 **257 个 bin**（0–6000 Hz，23.35 Hz/bin）；v6 用 `linspace(0,256,256)` 取了其中 **256 个（只跳过 bin 255）**，即 **256 维就是几乎全部频谱，不是降采样**。

而 42.67 ms 窗 + Hanning 的主瓣宽 = 4/T = **93.8 Hz**，相邻 bin 才 23.35 Hz —— **256 bin 已比物理分辨极限细 4 倍，是过采样**。

要拿 512 bin 只有 FFT 补零到 1024 点一条路（窗长不能动，否则破坏 42.67 ms 的跨数据集口径），而补零是 sinc 插值，**不增加任何信息**。900 rpm 时 BPFO(46.07 Hz) 与 BPFI(73.94 Hz) 只差约 28 Hz（❗旧版写 45.75/73.98 Hz 是论文图注常数，与本文其他各处用的 3.071/4.929 倍数不一致，已统一），远小于 93.8 Hz 主瓣 —— **无论 256 还是 512 bin，这两峰物理上都分不开**，补零解决不了。

**结论：256 不是"太细"，它就是这扇窗的物理极限；512 是花两倍输入维度买插值。保持 256。**

### 3.4 逐窗跨频标准化（= 窗口内标准化，**同一个操作的两个名字**）

❗初稿在 §3.3 把它写成两条"既有性质"，是错的。v6 里只有一次标准化：`preprocessing._shape_std`。"窗口内"说的是**作用域**（每窗独立做），"跨频"说的是**方向**（沿 256 个频率 bin 求 mean/std）——不是两步。

对每个 512 点窗：

```
x[0..511] → Hanning + rFFT → 幅值谱 A[f]（257 bin，取 256）→ log → L[f]
z[f] = (L[f] − mean_f L) / std_f L          ← 只用本窗自己的统计量
```

z 是 log 谱的**仿射变换**，等价于线性域的"任意正缩放不变"。由此：

**得到的**
- **对增益/单位完全不变** → PU 振动单位未标注被它直接消掉
- **保留峰-底比**（log 域仿射不改相对差）→ 共振峰、边带等物理 signature 完整保留
- **不跨窗口共享统计**（v6 注释明说：跨窗统计会把大能量窗口的幅值差异带进所有样本）

**失去的**
- **全部幅值/能量信息**：RMS、峭度幅值、"更严重 = 幅值更大"这类线索全部抹掉，只剩谱形
- **对加性噪声不不变**：`log(A+c)` 不是 `log A` 的仿射变换，噪声底的绝对高低会改变形状

**对迁移的双重含义**
- 好：域差异被压缩到"谱形"一维，MMD 要对齐的东西更纯粹
- ⚠️ `phys_envelope` 是在**原始信号**上算包络谱谐波比的，用了幅值信息；深度模型不用 → 两者**不是同一信息的两种算法**，对比时要写明

**推论**：这个特征天生**做不了损伤程度分级**。若将来加严重度任务，要换特征或加一路不标准化的输入。

## 4. 划分与评估单元

### 4.1 单元 = 轴承×工况 = 116 条（划分与评估同单元）

与 v6 的文件级划分同构（v6 的 `_0.._3` 是同一物理轴承的四档载荷，本来就被拆进池和测试）。代价与声明见 D5。

两个正交的轴，报告时都要能分开：

| 轴 | 层级 | 用途 |
| --- | --- | --- |
| **轴承×工况** | 116 | **划分与评估单元** |
| **轴承** | 29 | 补充指标："仅未见轴承"准确率（零额外算力） |
| **损伤来源** | artificial 12 / real 11 / none 6（主口径）；real 14 仅在含 KB 的事后分析里出现（32 轴承口径） | 分组报告 |
| **工况** | 4 | 分组报告（`N09` 与 `F04` 已实测为弱工况，见 `数据事实_CWRU与Paderborn.md` §2.8） |

### 4.2 源域四折

153 文件按类四折（`split_seed=0`）。**Normal 只有 4 个文件 → 每折验证集只有 1 个 Normal 文件**（双通道合计 238–474 窗——`Normal_0.mat` 是半长度文件，仅 119 窗/通道，命中哪折哪折的 Normal 验证指标更抖），这是数据本身的限制。**冻结记录里必须声明：源域 Normal 的验证指标方差天然很大，不据此调参。**

源域四个来源（`Normal`/`12k_DE`/`12k_FE`/`48k_DE`）**共享同一个分类头**，不另做留一验证；但训练时的源验证集指标必须按来源分组落盘，哪一路弱了一眼可见（零额外算力）。

### 4.3 少样本标注池怎么选（v6 选标协议的映射）

| v6 | v7 / PU |
| --- | --- |
| 单元 = 文件 | 单元 = **轴承×工况**（116 个） |
| 特征 = 512 维（DE+FE 拼接，因 v6 有双测点） | 特征 = **256 维**（单测点，本就是全部信息） |
| 候选集 = 45/52 个文件 | 候选集 = **116 个单元** |
| `K = Σ_j max(1, round(p·n_j))` | **改为按绝对预算 `K` 直接指定** |

流程照搬 v6：`logspec512` → 单元内窗口均值 → 候选集上 z-score → k-means 搜 `k∈[6,20]` 取最小够 95% silhouette 的 k → 每簇取 medoid。

**预算公式**：v6 的 `K = Σ_j max(1, round(p·n_j))` 在 **116 个单元上不再退化**（`k=6..20` 时簇大小约 6~19，`round(0.25×19)=5`、`round(0.25×6)=2`，各档分得开）——初稿写的"会退化"是把 29 轴承时的分析错误搬过来了。**仍然改按绝对预算 `K` 指定**：语义直接、与“标了几个单元”一一对应；2026-10-13 实跑 `k=19`，用户确认预算 **K19、K38、K116**（见 §5）。

**模型输入维度澄清**：v6 模型输入就是 `(B,1,256)`，DE/FE 是独立单通道样本；512 只出现在 v6 的**选标特征**里（因双测点拼接）。两侧模型输入都是 256，**不存在不对称**。

## 5. 实验矩阵（2026-10-13 冻结）

单臂 = (源构造, 适配方法, 目标划分)。

### 阶梯 1：零标注 → 少标注（主阶梯，本轮执行）

零标注一侧分两档：**纯迁移**（无监督域适应，不用任何目标标签）与**少标注**（用目标标签）。

| 臂 | 源 | 适配 | 目标标签用量 | 对应 v6 臂 |
| --- | --- | --- | --- | --- |
| `joint` | CWRU | 无（零样本前向） | 0 | `joint` |
| `source_continue` | CWRU | 纯源续训（步数对齐） | 0 | `source_continue` |
| `adabn` | CWRU | BN 统计重估，无梯度 | 0 | `adabn` |
| **`mmd_marginal`** | CWRU | **边际分布多核 MMD 对齐，无目标标签** | 0 | **无（新增，纯迁移入口）** |
| **`ce_K{k}`** | CWRU | CE 适配，`K = k`（每簇 1 medoid） | `k≈6~20` 单元 | `ce` |
| `ce_K38` | 同上 | CE 适配，`K=38` | 38 单元 | **Q2 标注预算曲线**（用户确认） |
| `ce_K116` | 同上 | CE 适配，全标 | 116 单元 | **全监督上界**（天花板参照） |
| `ce_mmd` | 同上 | CE + 逐类 MMD | `K = k` | `ce_mmd`（预期无净效果，作对照保留） |
| **`phys_envelope`** | 无 | **零训练物理判据**（包络谱谐波比当 3 类分类器） | 0 | 无（新增，D8） |

**`mmd_marginal` 是纯迁移学习入口（D10）**：只用无标签 PU 数据 + 源域标签，λ=0.3、固定核 σ=(1,5,10)、biased —— 配方与 v6 冻结的完全一致，只是从**逐类对齐换成边际对齐**。

⚠️ **技术约束**：v6 的 `classwise_mmd_loss` 按**真实标注**逐类对齐，没有目标标签就做不了，所以纯迁移臂只能用边际 MMD。这既是经典 DAN 路线，也正是论文标题里"深度迁移学习"应有的形态。

**预期位置**（写下来防止事后改判读）：`adabn` ≪ `mmd_marginal` ≪ `ce_K{k}`。若 `mmd_marginal` 不明显高于 `adabn`，那是一个值得报的负结果——v6 已测过"带标签的逐类 MMD 无净效果"，无标签的边际 MMD 更弱是合理的。

**实际选标与预算已冻结**：`selection.py` 在 116 个单元上选出 **k=19**（silhouette=0.257117，95% 阈值=0.244261），用户确认 **K19、K38、K116**。池是同一无标签代表序列的嵌套前缀；池/测试数量分别为 **19/97、38/78、116/0**，清单见 `outputs/selection/selection.json`。K116 是全监督拟合参照，**没有留出测试，不作为泛化过线证据**。

**无标签范围（2026-10-13 用户确认）**：`adabn` 与 `mmd_marginal` 使用全部 **116 个主口径单元的无标签信号**（不含 KB），不读目标标签、不按目标真值均衡采样。明确记为 **传导式适配（transductive）**：测试信号已参与适配，只能称目标标签留出，不能称测试信号完全未见。监督 CE/逐类 MMD 仍只用对应冻结标注池，`ce_mmd` 用 K19。

**全体与留出并报**：D3 的 116 单元阈值不变；监督臂的全体统计包含训练池，只作描述，另报自然留出。K19/K38 预算曲线另可在共同 K38 测试集上对照，K116 不加入泛化曲线。配对链使用共同 K19 测试清单，并明确无标签臂的传导式性质。

固定 `fold=0..3`、`seed=0..2`、8 个模型臂共 **96 格**，另有 1 个零训练物理基线。全部参数、臂清单、配对链与判据见 `configs/stage2.json`。**96 格训练与 108 份评估已于 2026-10-13 在云端执行完毕**（训练 96/96、评估 108/108，无失败格，判据与冻结配置未被改动），执行明细见 `../outputs/summary_2026-10-13/cloud_run_train_eval.md`。

**`phys_envelope` 是零训练、零标注的物理下界（D8）**：深度模型必须显著超过它才有意义。

### 阶梯 2：人工缺陷 → 真实损伤（**推迟**，阶梯 1 跑通后再做）

| 臂 | 源 | 目标（测试） | 回答的问题 |
| --- | --- | --- | --- |
| `art2art` | CWRU（全人工 EDM）+ PU-人工 | PU-人工（留出单元） | 人工→人工，域差只有"台架" |
| **`art2real`** | CWRU + PU-人工 | **PU-真实（留出单元）** | **人工训练的模型能不能认真实损伤** ← 阶段二最有价值的一条 |
| `artreal2real` | CWRU + PU-人工 + PU-真实（部分） | PU-真实（留出单元） | 加一点真实损伤能救回多少 |

### 阶梯 3：工况迁移（**推迟**）

`leave-one-condition-out` 四折：源 = PU 三个工况，目标 = 留出的那一个。

### 配对链（训练前写死）

已冻结：`joint ↔ mmd_marginal`、`adabn ↔ mmd_marginal`、`mmd_marginal ↔ ce_K19`、`joint ↔ ce_K19`、`source_continue ↔ ce_K19`、`ce_mmd ↔ ce_K19`。

### 每个臂必须同时输出三个数 + 两组分组

因为保留 4 分类头，**任何一个臂的单个数都不可解释**。每个单元固定输出：

- `E1`（四路准确率）、`E2`（三类掩码重判准确率，D6 冻结口径）、`P_ball`（Ball 误判率）；均在单元级（116）算、宏平均，记录级（2,319）并报；
- 按"损伤来源（artificial|real|none）"与"工况"两组分别报 —— `N09` 与 `F04` 已实测为弱工况；
- **双口径并报**：记录级（2,319）+ 单元级（116，主判据），见 D11；
- **补充**：按"该单元的轴承是否进过池"分组报（D5 的补充指标；仅当未见组非空时报，`ce_K116` 等全标臂除外）。
